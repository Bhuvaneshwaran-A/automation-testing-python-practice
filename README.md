## 🧪 Programs Covered

### 1. Binary Numbers Divisible by 5

**Requirement:**
Accept a sequence of comma-separated 4-digit binary numbers and identify the binary numbers that are divisible by 5.

**Input:**

```text
0100,0011,1010,1001
```

**Output:**

```text
1010
```

**Python concepts practiced:**

* `input()`
* `split()`
* `for` loop
* `if` condition
* Binary-to-decimal conversion
* String handling

---

### 2. Count Letters and Digits

**Requirement:**
Accept a sentence and calculate the number of letters and digits present in it.

**Input:**

```text
hello world! 123
```

**Output:**

```text
LETTERS 10
DIGITS 3
```

**Python concepts practiced:**

* String traversal
* `for` loop
* `isalpha()`
* `isdigit()`
* Counters
* Conditional statements

---

### 3. Factorial of a Number

**Requirement:**
Accept a number and calculate its factorial.

**Input:**

```text
8
```

**Output:**

```text
40320
```

**Python concepts practiced:**

* `input()`
* Integer conversion
* Variables
* `for` loop
* Mathematical operations
